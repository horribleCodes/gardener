# Hero: Feature creation

# Notes

- All properties are created by the MCP unless stated otherwise.
- Create a new campaign for this test.
- Seed: 22

## Steps

1. Make a level 3 hero with the Health Word, in a warded city, with a lesser priest resisting.
2. Instantly purge a village disease. Expect no Influence, no Dominion, and no ward cost.
3. Quote an Improbable city Feature that keeps the cure, with the ward and the priest. Expect base 2 plus 4 plus 1, times 2, so 14. A hero whose Words do not fit should be refused.
4. An ally commits part of the Influence. The hero covers some of the rest with Wealth, and 3 points of Influence must cost 6 Wealth.
5. The ally withdraws. The project collapses unless the hero covers the gap. Dominion already spent stays put.
6. Finish the gap with Dominion. A smaller opposing spend does not undo it. A spend at least as large does.
7. Attach the Feature to the ruling faction. Expect one new 1-point Problem.
