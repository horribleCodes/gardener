# Faction creation & progression

## Notes

- All properties are generated by the MCP unless stated otherwise.

## Steps

1. Create a new campaign with at least 2 factions.
2. Pick two factions, A and B. Add two additional factions, C and D.
  - **C:** In conflict with A. Name it after an animal.
  - **D:** A merchantile faction. Secretly supplies both A and C with weapons.
3. Set up the following: B used spies to learn that D is supplying both sides with weapons. B is now threatening D to reveal this to A to win favor.
4. Advance the campaign by 4 months.
5. Report what has happened since the campaign started.
